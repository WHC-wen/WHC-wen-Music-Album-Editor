# 声形 STUDIO

一款可以直接在浏览器中打开的音频与专辑封面编辑器。导入音频、裁剪拼接、设计封面，再把带内嵌封面的 MP3、WAV、PNG/JPG 或完整作品打包下载；素材处理全部在本机完成，无需账号、后端或构建工具。

![声形 STUDIO 仓库展示图](assets/social-preview.jpg)

> GitHub 仓库简介可填写：纯前端、离线可用的音频裁剪拼接与专辑封面编辑器，支持 WAV、高清图片和工程文件导出。

## 功能

- **音频编辑**：导入浏览器可解码的 MP3、WAV、OGG 等文件；查看波形，拖动端点或输入时间裁剪，分割片段、调整顺序、拼接和调节单段及总音量；实时播放预览。
- **封面设计**：上传图片或使用纯色画布；编辑专辑名称和演唱者，设置字体、字号、颜色、对齐、透明度与位置；拖动文字或贴纸，管理图层顺序和背景滤镜。
- **导出与继续编辑**：导出最高 3000 × 3000 的 PNG/JPG、内嵌封面与歌曲信息的 MP3 或 WAV、包含作品与源码的 ZIP；可保存并重新打开可编辑工程文件。

## 立即使用

1. 下载仓库中的 `index.html`，双击用现代浏览器打开。
2. 点击「导入素材」选择自己的图片和音频。首次导入音频会替换两段合成演示音频。
3. 在时间线裁剪与拼接，在画布和右侧属性栏设计封面。
4. 点击「导出作品」下载图片、MP3、WAV 或 ZIP。音频导出窗口会从封面文字预填歌曲标题、演唱者和专辑名称，也可单独修改；当前合成封面会写入音频文件。想在播放器里显示封面时，选择默认的 MP3。离开前可通过顶部保存按钮下载工程文件。

本项目只有一个运行文件：`index.html`。它已内嵌样例封面、图标、样式和脚本；README 中的图片只是仓库展示素材，不影响离线运行。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库，把 `index.html`、`README.md` 和 `assets/` 文件夹上传到仓库根目录。
2. 在仓库的 **Settings → Pages** 中，将 **Source** 设为 **Deploy from a branch**，选择 `main` 和 `/(root)`，然后保存。
3. 等待 Pages 发布完成，使用页面给出的站点地址访问。无需填写构建命令。

仓库社交展示图不会因为放在 README 中就自动设为社交预览。若需要分享仓库链接时显示它，在 **Settings → Social preview → Edit → Upload an image** 上传 `assets/social-preview.jpg`。

## 技术与范围

原生 HTML5、CSS3、JavaScript，使用 Web Audio API 解码/播放、Canvas 合成封面；不使用服务器、CDN 或运行时外部依赖。音频以 44.1 kHz 立体声导出：MP3 为 192 kbps，ID3v2.3 标签中写入歌曲标题、演唱者、专辑名称及合成的 JPEG 封面；WAV 为 16-bit PCM，写入 RIFF INFO 与 ID3 数据块。片段接缝施加最长约 3 ms 的短淡入淡出以减轻爆音。导入编码取决于浏览器支持情况。

WAV 文件可以包含封面数据，但播放器对其显示支持不一致；需要播放器显示封面时，请选择 MP3。完整 ZIP 同时提供独立的高清封面图。

MP3 编码使用随 HTML 一同内嵌的 [lamejs 1.2.1](https://github.com/zhuker/lamejs)（LGPL-3.0）。仓库的 `vendor/lamejs/` 提供原始发布版脚本与许可文本；本项目没有修改编码器本身。

为控制浏览器内存，单个音频文件限制 100 MB，解码音频合计约 320 MB，拼接时长最多 30 分钟；大型工程建议在桌面版 Chrome 或 Edge 中使用。关闭页面前应主动保存工程，页面不会自动保存作品。
